<p>原生住宅 IP 的报价单，通常只有两列：按月包多少、按量扣多少。但真正决定总花费的，是这两列背后的参数——有效天数、停机规则、计费单位、上下行是否都算、超量怎么算、退款怎么折算。同样的月费，参数不同，一年下来能差出好几成。这篇只讲计费参数，把两套模型的关键项逐条列出，再给一套"先短周期试、再续长期"的换算方法，让钱花在能算清的地方。</p>

<h2>一、两套模型的参数，先对着看</h2>
<p>先建立整体印象：按月包买的是"一段时间的使用权"，按量扣买的是"实际消耗的流量"。两者的风险结构相反。</p>
<h3>月包的关键参数</h3>
<p>有效天数、是否支持中途停机、单条线的并发与带宽上限、超量是否降速、续费是否锁价、退款按什么折算。六项里最容易被忽略的是"有效天数"：有的按自然月算，三十一天和二十八天价格一样；有的按三十天滚动，跨月更灵活。</p>
<h3>按量扣的关键参数</h3>
<p>计费单位（GB 还是请求数）、上下行是否都计、会话断开后重连是否重复计费、余额有效期、是否有阶梯价、超量后是断服还是继续按高价计。按量看着简单，实际口径差别很大，同一份需求在不同服务商那里能算出两倍差价。</p>

<h2>二、按月包：五个参数决定值不值</h2>
<p>月包不是付了钱就一直能用，有几条边界必须提前问清。</p>
<h3>有效天数与停机规则</h3>
<p>问三句：一个月按自然月还是三十天算；中途不用能不能停，停了是否保留原 IP；停多久后会被回收。第三句最关键——保留原 IP 是月包最大的价值，很多服务商停机超过七天就把地址释放，再开就是新地址，环境等于重建。</p>
<h3>并发与带宽上限</h3>
<p>一条线支持几个并发连接、单连接带宽上限多少，这两项直接影响能不能多号共用一条线。常见配置是单线十到五十个并发，够十个号日常使用；如果写着"不限并发"，多半有隐形的带宽总量限制，问清楚总带宽是多少。</p>
<h3>续费锁价与退款折算</h3>
<p>续费是否按首单价锁一年，这条对长期成本影响最大。退款方面，能按月折算的通常收一成左右手续费，不能折算的只支持换线。看不到退款条款的年付，本质上是把风险全留给自己。</p>

<h2>三、按量扣：三个口径决定实际单价</h2>
<img src="/tp.png" alt="原生住宅IP月包与按量计费参数对照核算">
<p>按量的坑集中在口径上，标价便宜不等于用得便宜。</p>
<h3>计费单位与双向计费</h3>
<p>有的按 GB 计且上下行都算，实际消耗是单向下行的一点五到两倍；有的只计下行，标价看起来高但总账更低。拿同一次操作对比：加载一个含图片的页面，下行两兆、上行两百 K，双向计费就是两点二兆，只计下行就是两兆，差距不大；但上传文档时差距会拉到十倍以上。</p>
<h3>重连与心跳的隐性消耗</h3>
<p>会话断开后重连，握手和心跳也走流量。长期挂着的号，一天心跳可能消耗几十兆，一个月就是一两 GB。这笔在小流量套餐里占比不低，问清是否计费、能否关闭无关心跳。</p>
<h3>超量与阶梯</h3>
<p>阶梯价通常是"用得多单价降"，但要在同一账期内累计，跨月清零。超量部分有的按原价续，有的翻倍。做预算时按"最坏情况"算：把预估流量的 1.5 倍乘上超量单价，看是否仍在可接受范围。</p>

<h2>四、短周期试到长期续，怎么换算</h2>
<p>这一步是整篇的落点：先用小钱买信息，再用确定的用量去买低价。</p>
<h3>试水期的成本控制</h3>
<p>试水建议选按量，充最小额度（常见五十到一百元），拿三到五条线跑七天。记录每天的实际流量，得出"单号日均流量"这个关键数。这一步花几百元，换来的是后面所有预算的依据。价格区间仅供参考，实际以当期报价为准。</p>
<h3>什么时候转月付</h3>
<p>用日均流量乘三十，得到单号月流量；再乘号数，得到月总流量。若月总流量超过月包所含流量的六成，转月付通常更划算；低于三成，继续按量更省。中间区间看月包是否锁价、是否需要保留固定 IP，需要就转，不需要就继续按量。</p>
<h3>混合用法的建议</h3>
<p>核心号走月包独享，锁定固定 IP；边缘号走按量，随用随停。这套组合的总支出通常比全员月包低三到四成，也比全员按量稳定。预算有限的团队优先采用这一种。</p>

<h2>五、签之前问清这六句话</h2>
<p>六个问题，得到明确答复再付款，含糊其辞的先按最坏情况算。</p>
<h3>六个问题</h3>
<p>一是月包按自然月还是三十天；二是停机是否保留原 IP、保留多久；三是超量是降速还是按高价续；四是退款能否按月折算、手续费多少；五是续费是否锁首单价；六是计费是否上下行双向。六句话问完，报价单上的两列才算真正读懂。</p>
<p>得到答复后一定要落到文字上。口头承诺波动大，让对方把六条答复以文字形式写进订单备注或聊天记录，出争议时有据可依。这一步花五分钟，能省掉后面很多解释成本。</p>

<h2>常见问答</h2>
<h3>月包中途不用，钱能退吗？</h3>
<p>答：多数不能整月退，但支持折算或转成余额。问清折算比例与手续费，超过两成手续费的，不如直接买短周期。年付前务必确认有书面退款条款。</p>
<h3>按量会不会比月包贵很多？</h3>
<p>答：低频使用不会，高频会。判断线是"单号月流量是否超过月包所含流量的六成"。低于三成按量更省，高于六成月包更划算，中间区间看是否需要固定 IP。</p>
<h3>固定 IP 一定要保留吗？</h3>
<p>答：长期挂号的号需要，临时用途不需要。固定 IP 的价值在于环境记录连续，一换地址就要重新建立信任。做订阅扣费和长期对话的号，尽量锁定地址。</p>
<h3>多条线能不能共用一份按量余额？</h3>
<p>答：有的服务商支持账户级共享余额，有的按线路单独计费。共享余额管理更简单，但要确认是否影响单线限速。买之前问一句，能省掉后面拆账的麻烦。</p>
